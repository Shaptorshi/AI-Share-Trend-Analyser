# 📈 AI Share Trend Analyser

An AI-powered stock market analysis platform built with **Next.js**, **TypeScript**, **PostgreSQL**, and **Prisma**. The application provides real-time market insights, technical indicators, watchlists, portfolio tracking, and AI-generated trend analysis to help users make informed investment decisions.

> **Disclaimer:** This project is for educational purposes only and does not provide financial or investment advice.

---

## ✨ Features

- 📊 Real-Time Stock Market Data
- 🤖 AI-Powered Trend Analysis
- 📈 Interactive Stock Charts
- ⭐ Personalized Watchlist
- 💼 Portfolio Tracking
- 🔍 Search Stocks by Symbol or Company
- 📉 Technical Indicators (RSI, Moving Average, MACD)
- 📰 Market News & Sentiment Analysis
- 🔐 Secure User Authentication
- 📱 Fully Responsive Design

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/Shaptorshi/AI-Share-Trend-Analyser.git
```

### Install Dependencies

```bash
npm install
```

### Configure Environment Variables

Create a `.env` file.

```env
DATABASE_URL=your_postgresql_connection

NEXTAUTH_SECRET=your_secret

NEXTAUTH_URL=http://localhost:3000

OPENAI_API_KEY=your_api_key
```

*(Replace or remove variables depending on the services you actually use.)*

### Run the Development Server

```bash
npm run dev
```

Open:

```
http://localhost:3000
```
